# Entrenador Entrevista STAR

Aplicación local para practicar entrevistas STAR con perfiles guardados en `localStorage`.

## Archivos

- `index.html`: esqueleto de la app.
- `styles.css`: estilos.
- `data.js`: perfil base y STAR stories iniciales.
- `app.js`: lógica de perfiles locales, filtros, simulación, cronómetros e IA.
- `api/claude.js`: proxy serverless para Claude en Vercel.
- `vercel.json`: rewrite `/api/claude` hacia `/api/claude.js`.
